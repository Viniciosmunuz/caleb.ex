# Hotel Calleb — landing page

## Como abrir

- Duplo clique em `site/index.html` para abrir em navegador local.
- Ou inicie um servidor simples na pasta `site/` com:

```bash
python -m http.server 8000
```

E depois acesse `http://localhost:8000`.

## Estrutura

- `index.html` — página final e markup principal.
- `DECISOES.md` — decisões editoriais e ajustes aplicados.
- `js/animations.js` — menu mobile e animações leves.
- `images/` — imagens locais usadas pela landing page.

## Observação

A entrega foi montada em um único arquivo HTML seguindo o contrato do projeto e a referência visual do Hotel Calleb, sem depender de bibliotecas externas para publicação local.
