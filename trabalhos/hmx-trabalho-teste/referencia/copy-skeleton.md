## Como usar este molde

1. Para cada seção, escreva a copy nova **dentro da faixa de palavras** do
   slot correspondente. Estourar em 30% já quebra o layout medido.
2. Onde houver `N cards`, produza **exatamente N** itens com a mesma
   anatomia — se o card tem ícone + título + texto, todos os N têm.
   Cards com quantidades de texto muito diferentes entre si é o defeito
   mais comum de copy gerada sem molde.
3. Preserve o **papel** de cada seção, não o assunto. `social-proof`
   continua sendo prova social ainda que a prova mude de depoimento para
   número, estudo ou logo de cliente.
4. Se uma seção da referência não fizer sentido no novo nicho, troque o
   propósito e registre a troca — não a apague em silêncio.
