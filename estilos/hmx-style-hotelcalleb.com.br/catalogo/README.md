# Catálogo de padrões

Especificações declarativas reutilizáveis encontradas nesta referência:
hover de botões/itens, fundos animados ou interativos, galerias e movimentos de
entrada. O catálogo guarda propriedades permitidas, sinais e proveniência —
**nunca corpos de scripts ou callbacks de terceiros**.

O montador do trabalho pode combinar estes padrões independentemente das referências
A/B/C. URLs são evidência; nenhuma biblioteca ou mídia externa é instalada ou
copiada automaticamente.
